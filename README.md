# ✈️ AI Trip Planner

AI Trip Planner is a full-stack web application that uses **Google Gemini AI** to generate personalized travel itineraries based on user preferences such as destination, duration, budget, and interests.

## ✨ Features

* 🤖 AI-powered itinerary generation
* 🧳 Personalized trip planning
* 🗺️ Interactive maps and location features
* 👤 User registration and authentication
* 📅 Trip creation and management
* 📱 Responsive user interface

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **AI:** Google Gemini API
* **Authentication:** JWT
* **Maps:** OpenStreetMap / Leaflet
* **Real-time:** Socket.IO

## 🚀 Setup

```bash
git clone https://github.com/sathvikaneela/AI-TripPlanner.git
cd AI-TripPlanner

npm install

cd server
npm install

cd ../client
npm install
```

Create a `server/.env` file using `server/.env.example` and add your own configuration.

### Run Backend

```bash
cd server
npm run dev
```

### Run Frontend

```bash
cd client
npm start
```
